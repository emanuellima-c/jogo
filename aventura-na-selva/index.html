Como jogar

Controles

A / D / ← / → para andar.
Espaço / W / ↑ para pular. Segure para ir mais alto.
X / J para atacar.
E para conversar com Bento.
Shift / K para dash, depois de aprender.
C ou segurar pulo na queda para planar, depois de aprender.
P / Esc para pausar. M para mutar.

No celular, use os botões de toque. Os puzzles aceitam toques e arraste; você também pode selecionar uma peça e tocar no destino.

Bento do Cipó

Após concluir uma fase, atravesse a área de descanso. Aproxime-se do mercador e use E ou toque em CONVERSAR. Compre vida, escudo e ímã ou melhore atributos. As melhorias ficam salvas.

Depois da fase 1, a prova de símbolos ensina pulo duplo. Após a fase 3, o jogo da memória ensina dash. Após a fase 6, reconstruir o mapa ensina planar. Tentar novamente é gratuito.

Suas relíquias e a escolha entre três presentes continuam disponíveis com Bento. Não há mais tela automática de upgrades.

Dicas de combate

Macacos e besouros podem ser derrotados pulando por cima. Tatus resistem pela frente. Chefes avisam seus ataques e mudam de padrão em três etapas. Totens acesos marcam checkpoints.

O projeto usa HTML, CSS e módulos JavaScript separados, sem bibliotecas ou recursos externos. Extraia a pasta inteira e abra index.html. Live Server e servidor Python também são compatíveis. O salvamento depende do armazenamento permitido pelo navegador. Use sempre o mesmo arquivo/local ou exporte seu progresso nas opções.
